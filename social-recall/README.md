# Social Recall — 日本史
教科書スキャンを参考に独自に記述した日本史の文章穴埋め学習サイト。GitHub Pages の `/Alts/social-recall/` で動作する静的アプリです。

## 内容
- 教科書 p.55〜109 を対象とした4章・16節・117段落。
- 3段階の出題（基本179、標準326、発展439個。難易度は累積式）。
- 「すべて学習」「未合格だけ」の2モード。
- 虫食い→回答表示→合格→合格解除の循環。合格と回答表示は別々に保存。
- ブラウザ保存キーは `sideworks:social-recall:progress:v1` と `sideworks:social-recall:settings:v1`。端末間同期なし。

## 編集
- `assets/data.json`: `chapters[].sections[].paragraphs[].tokens[]` で構造化。
- `{text:"..."}` は本文、`{id,answer,level,explanation?}` は虫食い。
- `level` は1/2/3。編集時は既存の `id` を維持して進捗を引き継ぐ。
- 公開先パス以外を編集しない。root の README/AGENTS を必ず確認する。

## 資料と限界
資料：ユーザー提供 `日本史s2t2m.pdf`（全28PDFページ、教科書p.55〜109）。
原文そのものではなく独自の文章に置き換えた。読み取りにくい箇所は歴史的事項に基づき再構成。強調・囲みの完全照合、外部資料との全件史実監査は未完了。書き込みが別資料にある場合、原資料の添付後に追加すること。
