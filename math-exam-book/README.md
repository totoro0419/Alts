# 数学試験対策 教科書 — 構造で解く

高校数学の試験範囲と授業問題7枚の数学的エッセンスをもとに構成した、オリジナルのWeb教科書です。

公開予定のURL: https://totoro0419.github.io/Alts/math-exam-book/

※ GitHub Pages のデプロイ成功・実URLの表示確認と、GitHubへのコミット成功は別です。

## 全13章

1. 線分比・面積比を設計する
2. チェバ・メネラウスと面積の連鎖
3. 方べき・円周角・接線
4. 四面体の体積・垂線・切断
5. 正四面体・内接球・外接球
6. 折り曲げ・合同四面体の成立条件
7. 弧度法・単位円・グラフ・周期
8. 加法・倍角・半角・和積の完全整理
9. 三角方程式・不等式・連立
10. 三角関数の最大・最小を体系化する
11. 文字定数と解の個数
12. 直線のなす角・36°・正五角形
13. 総合演習・解法の選択表・直前確認

## 特徴と制約

- 方針 → 計算 → 結論を基本とし、確認問題に解答を付けました。
- 数学Ⅲは扱いません。
- 既存の授業プリントを転載せず、発想を一般化してオリジナルの解説・類題を作成しました。
- 全ファイルはこの math-exam-book ディレクトリ内にあります。
- 静的なHTML・CSS・JavaScriptで動作し、ハッシュリンクを使用します。
- 数式表示には外部CDNのMathJaxを使います。接続不可の場合はLaTeXコードのまま見える場合があります。
- 進捗と配色はブラウザー内の名前空間付きlocalStorageに記録します。
- smoke.html は読込・章移動・進捗・検索・配色・狭い画面での表示など16項目を確認するためのページです。

## 配信

GitHub Pages 用ワークフローは .github/workflows/pages.yml です。既存の漢文教材用検査は維持した上で、本教材のディレクトリ変更でもデプロイが走る設定としています。ブラウザーでの実配信結果は別途検証が必要です。
